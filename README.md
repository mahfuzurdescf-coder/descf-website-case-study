# DESCF’s public conservation website

I planned, built, and launched the public website of the Deep Ecology and Snake Conservation Foundation (DESCF) in Bangladesh. The site helps visitors explore conservation programmes, learn about wildlife, and find ways to collaborate.

[Visit DESCF](https://www.descf.org/) · [Explore the snake guide](https://www.descf.org/bangladesh-wildlife/snakes) · [Try the multilingual search demo](https://mahfuzurdescf-coder.github.io/descf-website-case-study/DESCF_Search_Demo.html)

## Design and development

- **Clear routes for different audiences.** The homepage gives education, coexistence, and research distinct entry points. Programme pages explain the work, and the partnership page shows institutions how to engage.
- **Search by the names visitors know.** The snake guide supports Bangla, local, English, and scientific names. The standalone demo uses fictional records to illustrate alternate spellings, shared names, and searches with no results.
- **Reusable programme pages.** Next.js renders programme pages from structured content in Sanity, so programmes can share a consistent layout and link to relevant articles and resources.
